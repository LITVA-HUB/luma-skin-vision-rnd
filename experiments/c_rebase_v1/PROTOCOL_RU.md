# C_REBASE_V1 — фиксация до OOF

Это новый диагностический опыт, разрешённый владельцем 2026-09-15. Исторический C имеет статус **HISTORICAL_NOT_REPRODUCIBLE**; его метрики не являются критерием настройки или воспроизведения. Production/inference не изменяется.

Используется только ранее восстановленный MSKCC TRAIN: 966 изображений, 24 человека, 248 точных site/tag. Источники и признаки уже существовали до этого опыта. Новое — шесть обучений с нуля по новому mapping и связанный анализ OOF. Source-validation, calibration и test не загружаются в обучение.

`person_folds.lock.json` содержит полный список 24 псевдонимов и каждую OOF-строку. Полный mapping исходных IDs хранится отдельно приватно, его SHA256 включён в публичный mapping. Код `prepare.py` восстанавливает его из исходного TRAIN-manifest. Шесть folds по 4 человека распределены по устройствам без анализа targets: SHA256-сортировка внутри устройства, восемь SLR round-robin, затем шестнадцать iPod заполняют свободные места по номеру fold. В каждом fold есть оба устройства и оба типа изображения. Ручной балансировки по ошибке или цвету нет.

Один рецепт: color36 → Linear(36,64) → ReLU → Linear(64,3), 2563 параметра. Seed 17 для инициализации каждого fold; перестановки NumPy RandomState(17+fold). 100 фиксированных эпох, checkpoints 50 и 100; optimizer и RNG не сбрасываются на границе. AdamW применяется ко всем параметрам, включая bias: LR 0.001, weight decay 0.0001, betas (0.9,0.999), eps 1e-8, amsgrad/foreach/fused false. Batch 64, последняя неполная партия сохраняется. Loss — средняя MSE по трём стандартизованным Lab-координатам, gradient norm clipping 5. Нет scheduler, augmentation, output clamp, early stopping или отбора по holdout.

Нормализация X и Y — mean и population std только train-строк текущего fold, вычисленные в float64; std floor 1e-6. Обучение float32 на одном CPU-потоке, обратная нормализация float64. Препроцессинг/версии/хэши записаны в config, environment и freeze. Финальные OOF predictions появляются только после эпохи 100 каждого fold.

Диагностические квартили capture variability зафиксированы до OOF на 247 уникальных sites. Используется mean попарной ΔE00 наблюдаемого среднего цвета исходного центрального ROI. Пороги: 7.027119964117624 / 9.390654009555092 / 13.71375402081404. Единственный site без повтора выделяется отдельно. Старые p80-маски диагностики также неизменны. Они используют привилегированные повторные наблюдения и не являются правилом production-отказа.

Приборный target: среднее трёх Lab D65/10° assessments точного site. Наблюдаемый цвет: sRGB-derived Lab D65/2°. Между этими конвенциями физическая ΔE00 не вычисляется; разрешены только явно обозначенные coordinate-discrepancy proxies. Same-site target oracle тавтологичен, поскольку один target назначен нескольким снимкам. Все oracle помечаются **LEAKY_DIAGNOSTIC_ONLY**.

Аудит включает полные метрики, patient-bootstrap, strata и top-50, заранее заданные capture-квартили и маски, perturbation reference, точное разложение Lab-coordinate MSE на within-site prediction variation и site-mean bias. Это описательные компоненты ошибки фиксированного estimator, а не причинные проценты «датасет против модели».

После OOF исходная папка fold 0 переносится в quarantine, затем fold 0 обучается в новом процессе с нуля по тем же config/mapping/freeze. Основная проверка — побитовое совпадение predictions и model tensor hashes; заранее допустимый запасной atol 1e-6, rtol 0 требует объяснения платформенного расхождения. Запрещено менять рецепт после просмотра OOF.
