# Изменения архива

## 2026-09-14 · Исследовательская пауза и полный атлас

- Зафиксирована остановка исследований; HR runtime завершился ошибкой до паузы, P3/Seg2 остались подготовленными.
- Добавлены все новые исходники, протоколы, model cards, 88 карточек benchmark-каталогов, 39 run-каталогов и первичные журналы.
- Справочник 805 Python-модулей включает исторические snapshots; каталог 733 тестовых определений содержит полные условия и параметризацию.
- Таблицы отчётов: 212 таблиц /2377 строк. Полный исходный JSON/CSV сохранён отдельно.
- Семь AS-архитектур описаны по слоям, включая все unit/wide/linear HR варианты. Палитры, аналитические методы, локальное обучение, сегментация и инженерные пробы разобраны отдельно.
- Новая главная, декоративная обложка, source-backed графики, галерея и навигация на русском.
- Добавлены проверка копий/ссылок/таблиц/AST и GitHub Actions без обучения или доступа к данным.
