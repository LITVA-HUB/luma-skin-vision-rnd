# Skin risk crossing and native candidate-loss provenance

All new code is a local implementation using the existing CaptureColor backbone
and previously trained local Gaussian/ordinary models. No third-party weights
or external implementation was copied. Existing library dependencies remain.

MDNs, ensembles, covariance confidence, conditional risk minimization, kernel
mean embeddings and distributional/histogram regression are established ideas.
The full Gram factor and native-Lab endpoint do not themselves establish a new
invention. Affine versus simplex controls and the measured performance limits
are research evidence, not patentability or freedom-to-operate opinions.

Source data is original MSKCC CC-BY. Fixed loss dictionaries contain actual
TRAIN reference colors and stay in local ignored artifacts, along with image
predictions, identifiers and weights. Only aggregate results and code are
committed. The separate earlier CIE-derived branch retains its CC BY-SA terms;
no CIE buffers are used by these new image-loss models.

No public release, marketing claim, clinical claim or external communication.
