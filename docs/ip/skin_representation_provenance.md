# Representation-control provenance

The nuisance and copula families add locally implemented experimental methods,
not third-party model weights. They reuse the already documented original
MSKCC CC-BY image/reference release and original TRAIN/VALIDATION roles.
No additional external dataset, restricted weights or participant images are
added to Git. Refer to the existing dataset provenance for attribution and
separate data/code rights; this note is not additional commercial clearance.

Diffusion, ensembles, copulas, rank transforms and training-only branches are
not claimed as new inventions. The tested combinations have not established
a universal gain over ordinary controls. Preserve the negative results and
the exact-byte source locks, including the nuisance test-only FP64 amendment.
