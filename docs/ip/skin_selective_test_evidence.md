# Selective skin-color mechanism: independent-test decision

The mechanism combines compact patch color votes, contextual features,
within-image/seed disagreement and OOF supervision with actual instrument
DeltaE00. Voting, ensembles, error heads, isotonic calibration and Huber
iterations are not new on their own. No patent novelty conclusion is made.

After18OOFcolor fits and24matched candidate-head fits, the pre-test primary
comparison used identical color predictions with40 versus49risk inputs. Source
selection chose MLP for C+ and HGB for Proposed. The frozen test80%mean improves
4.333 to4.159, but the person-cluster confidence interval crosses zero. This
is a matched-search comparison; it does not isolate the added features under
the same selected head family. Ordinary fusion with density reaches4.145.
Do not describe this as an established novel-method advantage.

Preserve all old negative angular and synthetic hypotheses. Further development
must use source data only and a new independent confirmation cohort for a new
generalization claim. The original test cannot be repeatedly mined for winners.
Research test evidence and product camera independence remain distinct.
