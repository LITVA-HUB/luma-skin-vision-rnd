# Local-reference regression provenance

Original MSKCC CC-BY real photographs and native instrument Lab; existing
project descriptors and project-authored NumPy regression/evaluation code.
No new third-party implementation, pretrained weights, restricted data or cloud.
All inputs/methods are frozen with SHA256; private banks/identifiers stay out
of Git. A bank is model payload and must not be omitted from deployment size.

[Atkeson,Moore,Schaal,Locally Weighted Learning(1997)](https://link.springer.com/article/10.1023/A:1006559212014)
is explicit primary prior art for local weighted linear models, weighting,
regularization and prediction assessment. Its public publisher abstract was
checked on2026-09-11; no paywalled content was bypassed or purchased. No author
benchmark score is represented as a locally reproduced result. Gaussian
affinities, local affine fitting and reference means are not our inventions.

The local source gain is reproducible empirical evidence, not a patentability
claim. The failure against strong neural camera-transfer comparators is retained.
Combining neural features with local residual models needs an additional
matched-control and primary-prior-art pass before any novelty language.

The user's200,000 additional neural parameter allowance is recorded separately;
it does not permit claiming architecture novelty solely from a larger head.
