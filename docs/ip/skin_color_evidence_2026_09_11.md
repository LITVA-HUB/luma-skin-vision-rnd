# Skin-color evidence and asset lineage

No validated patent novelty is established by the new skin pilot. Source code
for seven ordinary regressors was implemented locally; the mechanism is standard
color calibration. He2021 original-author data are CC BY4.0, with attribution
in the report and immutable acquisition receipt. No model is trained on DAST,
CHROMA-FIT, ENCoDE or any non-commercial teacher/data in this pilot.

The related Liu2021 CC BY4.0 chart workbook and original CIE1931 BY-SA4.0 table
were used only for a provenance/correspondence diagnostic. That check failed;
its illuminant was not used to fabricate skin Lab labels. Preserve their own
attributions and the CIE table's share-alike terms separately from source code.

V7 source training remains SimpleCube++ CC BY4.0 plus standard DINOv2 Apache2.0
training-only features. INTEL evaluation is original CC BY-SA4.0 with explicit
sparse-mirror provenance limits. The real canonical-teacher comparison is
negative. No production model depends on the target-camera evaluation data.

Measured categories: V7 color-constancy component metrics; He single-camera
regional skin XYZ calibration. Still unmeasured: V7/Luma image-to-skin Lab,
phone-held-out facial DeltaE00, arbitrary lighting/ISP, cosmetic outcomes,
deployable calibration guarantees. None of the latter are implied by a small
coordinate-space error or an angular benchmark.
