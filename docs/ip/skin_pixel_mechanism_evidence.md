# Skin pixel mechanisms and claim boundaries

Local code and original CC-BY MSKCC data produced the measured source results.
No external pretrained skin weights or foundation-model inference is used.
The standard CNN comes from installed torchvision0.23.0 (BSD-3-Clause).
Own training produced all checkpoints; retain original dataset attribution
and separate code/weight/data rights. No public distribution occurred.

Patch-set learning, confidence weighting, robust M-estimation and ensembling
are established techniques. The current implementation and its improvements
over compact local baselines do not establish a patentable invention. The
proposed iterative contribution did not reliably beat plain matched pooling.
The forced-local variant also lost. A slight source ensemble gain must not be
promoted as an independently verified special mechanism.

The next scientifically defensible question is whether true skin-color
residual supervision and calibrated rejection improve accepted DeltaE00 over
a matched standard error head. That experiment has not been completed.
Ordinary facial-phone accuracy and entirely new-camera generalization remain
unvalidated. Existing Skolkovo wording is candidate technical positioning,
not approved legal classification or evidence of regulatory suitability.
