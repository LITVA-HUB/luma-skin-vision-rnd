# Privileged-reference diagnostic evidence

Implemented: excluded-person source-reference offset comparator and independently
verified native-Lab residual-energy decomposition. This comparator uses additional
instrument references and is NOT the single-image/no-calibration product model.

Measured:180 corrected arrays from90 existing source predictions. Full correction
can worsen SLR-to-iPod color errors while helping reverse transfer. Thus a shared
offset does not consistently explain acquisition-transfer failures. No achieved
production accuracy improvement is claimed. [Decision](../research/skin_offset_diagnostic_next_decision.md).

Audited:324 excluded-person folds and own-reference perturbation checks,42768
scalar CIEDE2000 cases,1620 coverage rows and180 Euclidean residual identities.
361 tests pass. Primary model scores and independent MSKCC test are unchanged.

Still unvalidated: new image-dependent mechanism, camera-independent skin color,
ordinary facial phones, calibrated refusal, cosmetics matching and innovation
advantage. This is diagnostic R&D evidence, not an approved legal classification.
