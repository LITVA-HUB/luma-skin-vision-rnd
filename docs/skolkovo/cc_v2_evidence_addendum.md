# Public camera-transfer evidence for the technical project — CC v2

Candidate positioning remains: **Compact adaptive color-normalization and reliability estimation technology for camera-independent analysis of color-sensitive visual objects, with the first commercial application in facial skin analysis and cosmetics recommendation.** This is a technical positioning draft, not an approved legal classification or a claim of Skolkovo eligibility.

The component takes one preprocessed linear camera image, estimates normalization and expected reproduction error, and accepts or refuses correction using a frozen rule. It uses local compact inference, with no foundation model, cloud dependency, camera CCM or target-camera calibration set. Single-image photometric statistics are used; cross-image target-domain fitting is not. Sensor decoding remains format-dependent; arbitrary smartphone JPEG processing is outside validated scope.

Permitted technical wording: “We validated the photometric normalization/reliability core of the future Luma Skin Vision Engine on established color-constancy data with real ground truth, using a documented custom unseen-camera transfer protocol.” Accompany it with the matched comparison and limits. Do not say “we proved skin-color accuracy”, “works on any camera”, “guaranteed error bounds”, “new uncertainty-aware color constancy”, or “state of the art”. Cheap-control risk80 intervals include no difference; the exploratory GW-residual model is better in full mean.

Original source licenses take priority over mirror badges. INTEL-TAU imagery/GT never fit weights or thresholds. Mirror files are authenticated to a pinned revision; original full-archive byte identity remains unverified. Dataset-dependent reports retain attribution and conditions. No dataset, model, report or application was published externally.

Next: continue camera-transfer R&D using independently held-out multi-camera source validation and stronger compact published controls; preserve this observed test population for regression only. A proprietary instrument-paired facial dataset is unavailable now and is not an immediate blocker. Skin-specific colorimetric validation remains future work requiring a facial dataset with appropriate reference measurements. Formal application, legal classification, team/commercial evidence and current filing requirements remain separate workstreams.
