## Как читать этот архив

Карточка серии ведёт к исходному отчёту, протоколу, подробному справочнику реализации и тестам. Таблицы в карточке дословно повторяют отчёт. Отчёты и исходные JSON сохранены отдельно, чтобы читатель мог проверить интерпретацию. Семейства, seeds, настройки, повторные оценки и отдельные архитектуры не складываются в один рекламный счётчик моделей.

Сначала выясните **задачу, единицы, данные и способ выбора**, затем сравнивайте цифры. ΔE00 цвета кожи, угловая ошибка освещения и IoU маски отвечают на разные вопросы. В этом архиве нет единого процента «правильно распознанных селфи».

Исторический этап 10–11 сентября: [большой исследовательский текст](../../publication/RESEARCH_REPORT_RU.md), [прежняя главная страница](../../../README.history.md), [история и соответствие коммитов](../../publication/HISTORY.md). Датированные `next`/`active` в старых документах — история решений. Они не отменяют остановку 14 сентября.

## Статус доказательств

| Статус | Что он означает |
|---|---|
| Сохранённый результат | Есть измерение и описание выборки; само по себе не означает независимую проверку |
| Аудит пройден | Определённая в протоколе проверка сохранённых результатов прошла; смотреть её охват |
| Отрицательный результат | Реализация проверена, но гипотеза не получила заявленного преимущества |
| Неполная серия | Часть работы выполнена; отсутствующие этапы явно перечислены |
| Подготовлено | Есть код, протокол и предварительные проверки, но основного результата ещё нет |

Декоративная обложка создана ImageGen. Количественные графики строятся из сохранённых чисел; происхождение и оформление описаны в [DESIGN.md](DESIGN.md).

Полная дополнительная история запусков: [39 run-каталогов](RUNS.md), [все записи моделей CSV](model_records.csv). Записи могут повторяться в контрольных receipts и не считаются новыми обучениями.
