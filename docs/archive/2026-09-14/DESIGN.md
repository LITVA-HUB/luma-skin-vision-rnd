# Оформление и происхождение визуальных материалов

[Архив](README.md) · [Манифест обложки](design_manifest.json)

Целевая поверхность — существующий GitHub-репозиторий; основной читатель должен быстро перейти от результата к архитектуре, протоколу, тесту и первичному файлу. Основной язык — русский, имена моделей и идентификаторы кода сохраняются.

## Применённые решения

- Product Design: осмотр существующего README в браузере; сохранены удачные ссылки и историческая научная детализация. Новая главная разделяет краткую карту результатов и глубокий справочник; длинные определения кода раскрываются по необходимости.
- Creative Production: использованы правила точного содержания и происхождения. Одна декоративная обложка создана встроенным ImageGen; реальные результаты не генерируются нейросетью. Прямой вызов доски этого плагина в текущем подключении был недоступен.
- Open Design: приложение/MCP в текущем окружении не найдено; его генерация и публикация не заявляются. Архив оформлен доступными средствами без установки нового приложения.
- Стиль: тёплый белый фон, тёмно-синий текст, умеренный teal и copper; научные графики имеют подписи единиц и явные ограничения.
- GitHub light/dark: количественные диаграммы имеют собственный светлый фон; смысл не передаётся одним только цветом. На узком экране текстовая навигация остаётся доступной, широкие технические таблицы прокручиваются.

Обложка — абстрактная призма и спектральные плоскости; никаких лиц, сертификатов, логотипов партнёров или обещаний точности. Призма не является схемой экспериментальной установки. Количественные PNG/SVG создаются Matplotlib из сохранённых JSON и имеют отдельный provenance. Mermaid описывает устройство/интеграцию, а не выдаёт планируемый компонент за проверенный продукт.

Проверка оформления включает просмотр реального GitHub README и страниц атласа после публикации. Автоматическая проверка ссылок дополняет визуальный просмотр, но не заменяет полноценный аудит доступности.
