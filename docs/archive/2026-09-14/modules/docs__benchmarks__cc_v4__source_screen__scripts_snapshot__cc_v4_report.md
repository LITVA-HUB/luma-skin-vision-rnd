Audit and publish the matched V4 source-development screen.

This report reads illuminant GT only for the 119 recorded SimpleCube++
development-validation rows. It does not load model weights, source test/risk/
calibration GT, INTEL-TAU data, or any image unless an invalid-input diagnostic
is required. The generated evidence is model-selection evidence, not an
independent benchmark, calibrated reliability result, or skin-color result.
