## Подготовка и контроль утечки

CelebAMask-HQ: проверены распаковка/декодирование, бинарность масок и совпадение RGB-каналов масок. Маска кожи строится как skin∪nose с вычитанием остальных 16 классов; сохраняется RGB192 и binary-mask192. Разбиение объединяет авторский person code OR точный хэш изображения транзитивно; более приоритетная отложенная часть защищается исключением конфликтующих строк, затем удаляются байтовые дубликаты. Исходные файлы не уничтожались. Коды авторов используются для группировки, а не выводятся моделью по лицу.

27 точных JPEG-дубликатных пар, из них 7 между авторскими частями. После очистки TRAIN/VAL/TEST не пересекаются по авторскому коду, точному хэшу и консервативной группе внутри Celeba. Совпадение человека между LaPa и Celeba этим не исключено. Отсутствие точного хэша не исключает другой crop/перекодирование.

Отдельный cross-source screen использовал только 44 710 TRAIN/VAL-строк LaPa+Celeba: 477 193 024 пар /954 386 048 normal/flip-представлений. DCT Hamming≤8 дал 175 кандидатов; 0 прошли пороги сильного совпадения correlation≥.995 и MAE≤8. Это отрицательный результат конкретного screen, не доказательство отсутствия одинаковых людей. TEST этим поиском не преобразовывался. [Протокол](../../data/skin_cross_source_similarity_v1_protocol.md).

UMINHO: пять validation и пять test-кубов не входят в тренировочную палитру. Источник/роль — единица разделения; миллионы связанных спектров нельзя считать миллионами независимых наблюдений. Расчётные RGB/XYZ/Lab из спектра сохраняют собственные допущения интегрирования и стандартного наблюдателя. [P1](../../benchmarks/skin_spectral_palette_v1/report.md), [P2](../../benchmarks/chromaseed_palette_pretrain_v1/report.md).

## Что не было получено или использовано

Hyper-Skin описан авторами как 306 кубов /51 человек с процедурой запроса доступа/EULA; сами данные не получены. Для global skin-color study на 2777 участниках индивидуальные данные обозначены недоступными; новый набор не появился. Повторная ссылка DOI 962049 ведёт к уже используемому MSKCC и не считается расширением. [Журнал последнего поиска](../../data/skin_data_expansion_round3_2026-09-14.md).

Частные пять фотографий не опубликованы и не получили выдуманных меток Lab. Не выполнялось определение личности или этнической принадлежности. Новый публичный архив содержит код и документированные выводы; фотографии участников, исходные маски и сырые массивы остаются в хранилище данных.
