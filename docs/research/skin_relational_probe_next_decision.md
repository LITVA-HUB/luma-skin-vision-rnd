## Next: test query-dependent support on the actual color endpoint

Do not launch a large learned relation network yet. The potentially useful part
is selecting compatible TRAIN support, not repeated additive comparisons. Test
this first with inexpensive standard local regressions. This is a comparator
and mechanism screen; it must not be renamed as novel technology.

Use the same original TRAIN leave-one-person-out roles and fixed color36
descriptors, excluding the query person from bank, scales and every regression.
Keep global ridge as exact control. Investigate two query-dependent affinities:
appearance distance in standardized descriptors and DeltaE00 distance between
base-ridge predicted colors. Both use only image information at inference.
Use simple reference-weighted mean and local affine regression controls to
distinguish reference averaging from transferring a local color relationship.
Freeze bandwidths, ridge penalty, weight normalization and all selection rules
before results; include the uniform-weight limit that must recover global ridge.

Mechanism: local support may adapt the appearance-to-Lab mapping to conditions
inferred from the image. Key assumption: descriptor/color proximity identifies
a transferable local mapping across people. Failure: proximity tracks camera,
texture or an already wrong color estimate, amplifies sparse-support noise or
merely regresses toward common skin colors. No camera identity or test-time
reference/calibration is allowed. Every bank embedding, target and operation
counts toward final model bytes/compute if this becomes a deployed candidate.

Score absolute native-Lab DeltaE00, p95 and person means. A ranking-only gain
does not justify expansion. If local support improves this screen, freeze
source known/unseen-camera experiments before any novel learned weighting and
compare with strong compact models and matched C+. Do not reuse exposed TEST
or CAL for tuning or imply a new independent result from reused source data.
If it loses global ridge, record the loss and reconsider the compatibility
representation before increasing network complexity.
