# ChromaSeed C: person-excluded residual supervision in the compact H model

2026-09-13. Registered before any C real-data fit. Broad autonomous compact/fast/high-quality goal remains active. H was verified progress, with a small mixed gain but worse transfer and higher response cost. Original TRAIN only, no legacy validation/calibration/test, new data, agents, downloads or publication.

## Prior evidence and bounded question

The archived `skin_crossfit_correction_v1` already tested full/matched/excluded-person supervision for a much larger neural model; the excluded-person hypothesis did not win. This study is a new compact-kernel ablation, not a new invention or a first test of cross-fitting. It uses H's same27,503B/24,278B hybrid schema, original128 shared row landmarks, projected16/tau.5 coordinates and analytical correction. No changes to inference, architecture, input features or readout losses.

Test whether residual targets from an excluded-person teacher improve **fixed H configurations**, with a matched inclusion control from the same teacher pool. Do not expand the projection or regularization grid. All H results and adverse histories remain. No hyperparameter or model-family choice may use C outer results.

Use the same three original-TRAIN roles and seeds17/29/43: mixed734fit/232held, SLR323fit/643held, iPod643fit/323held. These roles/people were repeatedly reused and are exploratory, not independent validation. Current C does not produce a new inner selector: it freezes the12 existing H inner-selected loss×uniform/support settings (two losses×two kinds×three roles) before any teacher fit. Both new arms use exactly those alpha/rho/power values. H's original inner selections have already used their inner folds; do not call them new C OOF quality estimates. Zero correction, ordinary blend and projected-only are preserved as exact H controls, without a post hoc choice to switch back.

## Teacher routing and boundaries

For each original role fitting bank independently, fit one raw H/A joint-soft alpha0.1 teacher excluding **each whole fit person**, for each seed and normalized/perceptual loss. Every teacher's weights, moments, exact width,128 raw landmarks, target metric and gate are computed solely on its remaining people. It must never see the role's held people or its own excluded person's rows/targets. Teachers use n-1 people, reducing the support-size shift compared with the previous three-fold large-network study. The final student's backbone still uses n people, so a shift remains.

Sort unique person identifiers within each camera group. For row i of person p, `out_person` uses the teacher excluding p. `in_matched` uses the teacher excluding the next cyclic person of the **same camera**; that teacher did see p. Each camera group must have at least two people. The same teacher pool/counts/settings is reused by both arms. Each row's paired teachers have equal person counts and equal camera-group person counts, but image counts and actual training people still differ. This is a matched inclusion control, not a causal proof or exact image-distribution match. Routing uses fit metadata only; deployment receives no person/camera labels.

Each teacher predicts all current bank fitting rows in native Lab; save these tables and model payloads with private row-index bindings. Route one teacher per row, with no ensemble. The projected correction targets are `(native_target - routed_native_teacher_prediction) / student_y_std`; target means/scales from different teachers must not be mixed directly. Student moments/projection/gate/metric are original role-fit only, matching H. The correction design is H uniform D or H mean(Kraw)^p D. The student's raw backbone stays fixed and is exactly reproduced from A/H. At deployment both arms add their correction to this same full-data backbone, never to an excluded teacher.
