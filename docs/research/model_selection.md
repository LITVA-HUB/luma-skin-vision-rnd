# Compact model selection — 2026-09-10

Decision for the first engineering iteration: torchvision MobileNetV3-small with `weights=None`. Replace its task head with continuous color regression; keep the same backbone for C and experimental C+. This is a random-initialization smoke prototype, not a pretrained or strong tuned scientific baseline. The official builder defaults to no pretrained weights; the published classifier has 2,542,856 parameters, but our modified model must be counted from the actual checkpoint. [Torchvision documentation](https://docs.pytorch.org/vision/stable/models/generated/torchvision.models.mobilenet_v3_small.html).

| Candidate | Mechanism and suitability | Provenance and decision |
| --- | --- | --- |
| MobileNetV3-small (2019) | Established inverted-residual compact CNN; available in existing PyTorch stack; practical CPU smoke and export path | torchvision BSD-3-Clause source; random init avoids a pretrained artifact. Selected for infrastructure. ImageNet weight/data rights remain separate. |
| MobileNetV4 (2024) | Universal inverted bottleneck / mobile attention; strong candidate for a later accuracy/latency comparison. Paper's 87% ImageNet and 3.8 ms Pixel 8 EdgeTPU are Hybrid-Large classification results, not Luma results or an 8 GB training measurement | [Paper](https://arxiv.org/abs/2404.10518), [official implementation](https://github.com/tensorflow/models/blob/master/official/vision/modeling/backbones/mobilenet.py), Apache-2.0 code. Checkpoint and training-data clearance not verified. Avoid adding TensorFlow merely for the smoke test. |
| MobileOne (2022/2023) | Training-time branches reparameterized into simple inference blocks; evaluate fused/unfused equivalence before export | [Official source and license](https://github.com/apple/ml-mobileone). Apple custom copyright license, acknowledgements and no implied patent grant; external checkpoint scope and ImageNet provenance need review. Candidate, not adopted. |
| FastViT (2023) | Hybrid token mixing with structural reparameterization; small variants could serve student or stronger baseline; compare on this color task | [Official source](https://github.com/apple/ml-fastvit), [license](https://github.com/apple/ml-fastvit/blob/main/LICENSE). Apple custom terms plus component acknowledgements; checkpoints/data separately unverified. Candidate, not adopted. |
| DINOv2 (2023) | Frozen features or teacher candidate; representation invariance may discard useful color and larger variants exceed compact target. Color fidelity must be tested | [Official repository](https://github.com/facebookresearch/dinov2). Original DINOv2 code/weights Apache-2.0; training corpus rights not thereby licensed. Current repository contains other models with distinct terms, including noncommercial X-Ray DINO. Pin exact family, artifact and license. No teacher adopted. |

Training-memory expectations are PLANNED, not measured: start at low resolution and batch size on RTX 4060 8 GB, use FP32 for reference, profile actual allocated/reserved memory, then assess mixed precision. Parameter count alone does not establish memory fit. All local latency, VRAM, file size and color accuracy results belong in benchmark artifacts, not copied paper tables.

No pretrained weights are downloaded automatically. Before optional pretraining: record URL, SHA256, upstream revision, weight license, training datasets and restrictions, notices, and intended fine-tuning/distillation rights. Unknown is COMMERCIAL USE NOT CLEARED. Distilling a restricted teacher does not remove its restrictions. Do not use color-jitter invariance blindly: augmentation must preserve or explicitly transform the physical target. Train-only normalization and subject splits are required.

Real-data selection: first tune C versus classical methods; then compare backbone candidates under equal data and tuning budgets; evaluate ΔE00 and selective risk/coverage, including device holdouts. Deploy only after a measured advantage. Compare exported FP32/FP16/INT8 output to a frozen native checkpoint and recalibrate if error ranking or accepted coverage changes.
