## Combine the surviving mechanisms within the new capacity budget

The user authorizes up to200,000 additional parameters. The current single
base has929,297; the next cap is1,129,297 neural parameters. Record this budget
in [the capacity specification](skin_capacity_budget_2026_09_11.md). A concrete
193,795-parameter adapter would yield1,123,092, with equal active counts for
an ordinary C+ residual head. Reference-bank storage is extra payload that must
be explicitly accounted for, not hidden outside a neural parameter count.

Next hypothesis: combine a strong compact neural color/context representation
with a small learned local-reference residual correction. The neural core has
better source transfer than raw-statistic ridge; the local-affine stage has a
real gain over ridge within its representation. Whether combining them helps
is UNVERIFIED. Local/deep kernels, differentiable regression, residual heads
and gating are established ideas; do a focused primary-source pass before
asserting any narrower novelty.

Use a small, fixed comparison: unchanged base, ordinary residual-head C+ and
proposed reference-conditioned correction, same backbone/data/budget. Start
with one correction pass and no inference metadata. Preserve equal initial
base color predictions through zero-initialized correction outputs. Train
queries must exclude every image/reference of their person from a support
bank; validation people must be absent from both encoder training and bank.
If a frozen encoder was previously selected on the reused source validation,
state that exposure instead of claiming fresh independent evidence. Freeze
seeds, reference support, regularization and source protocols before fits.

Main failure mode: the bank transfers acquisition-specific residuals or trusts
an erroneous base color. Other failures are high-dimensional local regression,
too little support, memorization, training-residual optimism and worsening
rare-color tails. A larger adapter alone is not a mechanism win: it must beat
equal-capacity C+ and the unchanged strong model on actual native DeltaE00.
Confidence-head training must later use correctly person-excluded color
residuals; do not recycle in-sample bank residuals as calibrated error labels.

The user's repeated-refinement idea remains relevant after a useful first pass:
a separately frozen0/1/2/3-step or damped feedback test can ask whether revised
color estimates improve reference matching. Iteration is not extra physical
evidence and may reinforce an unsupported-camera error; it must not be added
blindly to the currently weak raw-descriptor transfer model.
