## Exact definition of the Gaussian variants

For one normalized input x, let W1,b1,W2,b2 denote current parameter means and V1,vb1,V2,vb2 their elementwise variances, all FP64. Form hidden preactivation m=W1x+b1 and v=V1(x²)+vb1; a=max(m,0), j=1[m>0], u=j²v. Output mean t=W2a+b2. Write `D=diag(V2(a²+u)+vb2+sigma²/weight)`.

In full3, innovation covariance `S=W2 diag(u) W2.T + D`. In diag, keep only `diag(S)` and use componentwise inverses. Set q=S^-1(y−t), and c=diag(W2.T S^-1 W2). All reverse quantities are computed from the same pre-update means/variances, before any array mutation.

Output weights: `ΔW2=(V2*a[None,:])*q[:,None]`; `ΔV2=−(V2*a[None,:])²*diag(S^-1)[:,None]`. Output bias changes are `vb2*q` and `−vb2²*diag(S^-1)`. Hidden-layer weights: with g=j*(W2.T*q) and h=j²*c, `ΔW1=(V1*x[None,:])*g[:,None]`, `ΔV1=−(V1*x[None,:])²*h[:,None]`; bias changes are `vb1*g`, `−vb1²*h`. These are the diagonal parameter marginals of local Gaussian conditioning after a hidden-state smoothing step; no new forward evaluation on already-updated W2 is allowed during this observation.

After every update, variance floor1e-12. Count all entries below that floor and all negative pre-floor entries, per trajectory; retain the smallest pre-floor variance and checkpoint counts. Full3 has a positive semidefinite joint covariance construction; substantial negative values indicate an implementation problem. Diagonal output approximations may overcount correlated information, so their floor use is an outcome to report. No noise reset, variance inflation, mean clamp, process-noise rescue or post-hoc hyperparameter widening. Reject non-finite inputs; any non-finite fit state stops the run with explicit failure rather than exporting a plausible fallback model.

At deployment discard all posterior variances or Adam moments. Export FP32 parameter means, x/y moments and mean3 uint8 feature indices; all choices use the same deterministic mean network.
