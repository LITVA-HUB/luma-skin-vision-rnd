# Independent P3 verification consumers

This protocol implements the registered palette-transfer study without changing its training sources or endpoints. Preparation is progress, not evidence of native improvement. No subagent delegation.

Before any full audit, response benchmark, replay or report, require the actual HR and P3 workers to be terminal and dead. The caller must also observe successful terminal tool sessions. Verify the frozen P3 registration, production lock, selected inner heads, sealed HR source/artifact lineage and CPU/CUDA preflights. Keep full audit and runtime receipts separate from the preparatory initializer probe. Reject an unaccounted future recovery rather than inventing zero failure costs.

The independent initializer uses explicit architecture dimensions, seeded CPU random draws and a separately implemented affine normalization transform. It rebuilds every parameter in all six slots, checks exact initial-theta digests, preserves nonencoder initialization, matches each actual P2 seed/arm and validates metadata. It must not call the P2 transplant helper or P3 Bank to compute the reference. Production Bank may be used only as the observed subject of a clearly marked CPU preparatory probe. Original, aligned and shuffled are retained.

Probe completion cannot create audit.json, runtime.json or verification.json.

Freeze these consumers and tests before P3 production. All outputs are written once, with exact source/artifact dependencies. Existing completed measurements are read and checked, never silently replaced. A full seal requires all expected counts, audits, runtime measurements, tests, source checks and reports. The broad quality goal remains active after an individually verified study unless its full objective is independently achieved.
