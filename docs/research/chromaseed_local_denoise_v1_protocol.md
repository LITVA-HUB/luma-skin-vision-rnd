# ND: bounded local denoising of continuous skin Lab

Registered design, 2026-09-13. The preceding forum turn is progress: it added primary-checked candidates and a current data/access registry. This numerical study follows NS, whose penalty expansion is closed. Broad goal remains active.

Inventory: R already learned four shared recurrent residual corrections from a ridge start, image patches and attention; it sometimes amplified camera-transfer error. G/H already used conditional corrections and earlier ChromaSeed used frozen random/palette heads. ND is not the first iterative, local or analytical model in this repository. Its different training target is a deliberately noised clean Lab state, inspired by [NoProp v2](https://arxiv.org/html/2503.24322v2). This is an original implementation of a continuous-regression adaptation, not a reproduction of the authors' classification experiment or a novelty claim.

Only original TRAIN cache d7e7b4b4fc4574d620cbac8364dd8bb91be51769f4045bb8b4ddf2ad840556e0, 966 rows / 24 people. Same mixed and two camera/person transfer roles and three person-disjoint inner folds. Inputs are prepared color36; no image extraction is timed or validated. Native D65/10-degree Lab. All means/stds fit unweighted on fitting rows in FP64, floors 1e-6, exported FP32. Normalize input in FP32; targets normalized from native FP64 then cast FP32. Person/site/image-balanced weighted sampling, batch64, with the existing R seed+9001 row sequences. No old validation/calibration/test, new images/data/weights/packages, agents or publication.

Five families, all ReLU and independently initialized unshared blocks:

- plain: 36 -> 69 -> 3, 2,763 parameters.
- local2: two 39 -> 32 -> 3 blocks, 2,758 parameters.
- local4: four 39 -> 16 -> 3 blocks, 2,764 parameters.
- blind4: same four blocks, but three state coordinates are always zero in training and prediction. Its 192 state-input coefficients are inactive; deployed parameters remain 2,764, effective active parameter count is 2,572. Do not call that an exact active-capacity match.
- e2e4: exactly the local4 architecture and inference recurrence, trained through its deterministic rollout, with losses on all intermediate clean predictions. This is the direct matched-architecture control for local versus end-to-end training.

No shared block weights. For K blocks let a[t]=sin(pi*t/(2*K)), s[t]=cos(pi*t/(2*K)), t=0..K. Force a[0]=0,s[0]=1,a[K]=1,s[K]=0. A local training state is z[t]=a[t]*y_norm+s[t]*epsilon, independent standard Gaussian noise per slot/step/block/example. Each block predicts clean y_norm from [x_norm,z[t]]. Sum block MSEs after averaging samples and three target coordinates. No gradient travels between local blocks. Blind4 uses zero state instead; plain has one ordinary MSE. E2e4 sums the same per-block clean-target MSEs along its connected rollout. At inference start z[0]=0, with no target or random seed supplied. After block clean prediction c[t], z[t+1]=a[t+1]*c[t]+s[t+1]/s[t]*(z[t]-a[t]*c[t]); final output is the last clean prediction. Intermediate diagnostics report c[t], not the scaled latent z[t]. Blind4 never receives the previous state. Fixed mean-noise initialization is a design choice, not an exact sample from the training prior.

Initialization uses separate deterministic NumPy generators per seed and block: seed+310003+1009*block. First and second weights uniform +/-1/sqrt(fan-in), biases zero. Draw noise independently with seed+510001, generated as (steps,K,batch,3). Same seed across learning rates receives identical initialization, samples and noise. AdamW beta(.9,.999), eps1e-8, decay .01, independent per-block norm clipping at5, including e2e4. Reuse the verified R BankAdamW with one leading optimizer slot per block; no cross-block clipping. Learning rates .001/.003, seeds17/29/43, checkpoints512/2048/8192. Sum independent slot losses, never average across slots. FP32 CUDA, deterministic algorithms, TF32 disabled. CPU eager smoke then CUDA eager/graph parity before the primary source lock. Capture warmups fully reset weights/moments/counter. No concurrent heavy jobs.

45 inner banks = 3 roles x 3 folds x 5 families, six independent seed/rate slots each. 270 trajectories, 810 checkpoint models. Evaluate all clean predictions from every stage. Per role/family choose rate and checkpoint by mean of three seeds' equal-person DeltaE00, then mean image p90, then fewer steps, then rate index. Six candidates each, 90 candidate score records, 15 choices. Never average seed predictions as an ensemble. Freeze choices before final fits/evaluation. Final 45 models trained separately (one slot) for honest standalone replay/timing; selected setting only.
