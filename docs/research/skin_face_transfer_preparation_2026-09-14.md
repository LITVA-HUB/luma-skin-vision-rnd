Каждый батч из 32 снимков включает 16 одинаковых для парных опытов примеров LaPa и 16 дополнительных примеров выбранного источника. Порядок общих примеров и случайные преобразования согласованы. Отчёт показывает 9 парных сравнений добавления данных и 12 сравнений более долгого обучения, включая отрицательные результаты.

## Следующие обязательные шаги

Сначала дождаться фактического успешного завершения HR и выполнить его зафиксированные аудит, runtime и отчёт. Затем выполнить P3 CUDA preflight, полное обучение и полную проверку. Только после этого допустимы:

```text
python -X utf8 scripts/skin_face_transfer_run.py preflight-cuda
python -X utf8 scripts/skin_face_transfer_run.py run
python -X utf8 scripts/skin_face_transfer_evaluate.py test
python -X utf8 scripts/skin_face_transfer_report.py audit
python -X utf8 scripts/skin_face_transfer_report.py runtime
python -X utf8 scripts/skin_face_transfer_report.py report
```

Каждый процесс должен действительно завершиться до следующего. Повторный запуск поверх неполных артефактов не допускается; возможное восстановление оформляется отдельно. Seg2 уже подключён к дашборду; его ML-запуск ожидает завершения и проверки HR/P3.

После полного запуска будет измерено совпадение маски кожи и ошибка извлечения **видимого цвета на том же изображении**. Последняя использует ручную маску и предположение sRGB/D65/2°, с минимумом 16 пикселей; покрытие и попарные пропуски учитываются. Ни одна из этих метрик не является подтверждённой точностью физического оттенка кожи на обычном телефоне. Новых измеренных пар «камерное фото — эталон Lab» этот эксперимент не добавляет.

## Проверка похожих копий между источниками, 14 сентября, 12:28 МСК

Завершён дополнительный поиск похожего содержимого изображений на 44 710 разрешённых TRAIN/VALIDATION строках: LaPa 15 914/1 692 и CelebAMask-HQ 24 112/2 992. Сопоставлены 477 193 024 пары между источниками, с учётом горизонтального отражения — 954 386 048 сравнений. Строки TEST не преобразовывались в признаки, маски и результаты нейросети не использовались. Целостность полных файлов массивов проверялась по хешам Seg2, включая байты невыбранных строк общего массива CelebA.

64-битный DCT-отпечаток с Hamming<=8 нашёл 175 пар-кандидатов. Ни одна не выполнила одновременно заданные до поиска условия корреляции grayscale>=0,995 и средней разницы RGB<=8/255: сильных кандидатов — 0, включая переходы TRAIN↔VALIDATION. Максимальная корреляция среди кандидатов 0,87652. У всех строк gray std>=8, поэтому малоконтрастные исключения не потребовались. Примитивы описаны в первичных документациях [SciPy DCT](https://docs.scipy.org/doc/scipy/reference/generated/scipy.fft.dctn.html) и [NumPy popcount](https://numpy.org/doc/stable/reference/generated/numpy.bitwise_count.html); пороги являются локальными правилами скрининга.

Четыре ближайшие пары просмотрены на изображениях 192×192. Фоны, одежда и расположение видимых предметов различаются; копий одного изображения в этой четвёрке не обнаружено. Это проверка содержимого, без вывода о личности людей. Остальные 171 кандидат визуально не проверялся. Кропы, повороты, сильные изменения, сходство людей при разных кадрах, повторы внутри одного источника и TEST этим поиском не покрыты. В пределах этого метода совпадений не обнаружено; независимость людей и отсутствие всех утечек остаются непроверенными.

Полный повторный запуск заново вычислил все 44 710 миниатюр и отпечатков из исходных разрешённых строк, повторил перебор и оценки всех кандидатов.
