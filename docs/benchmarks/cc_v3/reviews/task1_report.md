# Task1 numerical/model core report

Status: implemented; SYNTHETIC CPU engineering evidence only. No real images, ground truth files, GPU training, pretrained models or new dependencies were accessed. No commit made. Ownership limited to `scripts/cc_v3_model.py`, `tests/test_cc_v3_model.py` and this report.

## Architecture and API

`ColorFramePosteriorNet(mode='frame', width=192, layers=4, hypotheses=8)` has exactly **1,215,535 trainable parameters** in each of direct/diagonal/frame modes, with identical parameter names and shapes. Four graph blocks use 420 directed eight-neighbor edges on 64 fixed spatial tokens. Each token has 11 features: canonical channel means, population standard deviations, mean asinh and normalized x/y. The blocks use embedding/relative-feature gates, difference values and residual learned updates; pooled context has 64 dimensions. The point head starts at canonical Gray World; eight directional mixture components, logits and softplus concentrations are learned separately.

Frames select among all 560 lexicographically enumerated triples of 16 patch means. Scaling, determinants, SVD diagnostics and solves use FP64. Frames returned by the API are in **common-scale-normalized RGB**, so under transformed inputs the frame equality includes an immaterial positive scalar; normalized predictions and canonical GT directions preserve the stated projective identity. No pseudoinverse is used. Condition threshold is 1e6 and is not itself GL-invariant. Rank/invalid-input refusal uses an identity diagnostic frame, with original singular values, condition, selected triple, determinant relative margin and input scale exposed. Direct/diagonal controls are subject to their own frame invertibility: a rank-one image can be admissible for the identity/diagonal control even though its full color frame is refused.

Forward exposes all required fields plus `raw_pred`, `input_valid`, `frame_valid`, `point_valid`, `frame_singular_values`, `frame_condition`, `frame_indices`, `frame_volume_margin`, `input_scale`. `raw_pred` is the unclipped camera-mapped point for a separate positivity penalty. `valid=frame_valid & point_valid`; rejected rows return a finite strictly positive Gray World diagnostic (a 1e-8 floor is confined to fallback). Negative, NaN and infinite input pixels are sanitized for that diagnostic computation while their original input-validity mask remains false. Minimum supported H/W is 8; malformed shape/nonfloating/empty batch raises a descriptive ValueError.

`canonical_target(frame,gt)` normalizes an FP64 solve and requires positive finite GT and finite nonsingular frames. `posterior_nll(output,gt,reduction='mean')` averages only valid-frame/positive-finite-GT rows, independently of point validity. All-invalid mean raises ValueError; `reduction='none'` returns NaN on excluded rows. The runner must never convert an all-invalid likelihood to a silent zero objective. `camera_posterior_nll` additionally applies the spherical pushforward log Jacobian `log(abs(det B)) - 3 log(||Bq||)`. Canonical NLL values across frame modes are not directly comparable; camera reproduction error remains the primary architecture-selection metric.

## Posterior transport and mathematical limitations

`transported_risk(frame,pred,directions,logits,concentration,frame_valid=None)` uses 32 deterministic vMF nodes per component (256 for default K=8): four midpoint polar CDF quantiles times eight azimuths. The vMF polar inverse is `z=1+log(u+(1-u)*exp(-2*k))/k`; small k uses the uniform limit. A least-aligned coordinate axis defines each tangent basis. Component weights are softmax logits, with equal weights inside each component. The 32-node rule is low-order numerical quadrature, has orientation and validity-boundary artifacts, and is not asserted to approximate a physical expected error to a guaranteed precision.

Each node is mapped through B, then its camera reproduction angle relative to the point prediction is computed. Nonpositive/nonfinite mapped nodes receive diagnostic cost 90 degrees; invalid mass is retained, not renormalized away. Invalid frames receive exactly risk90/mass1. For an invalid point with a valid frame, the risk is relative to its positive GW diagnostic, and `valid=False` must prevent selective acceptance. No raw proxy is a calibrated bound.

The SYNTHETIC one-component counterexample produces risk18.1674999212 degrees with identity B versus9.3703224581 degrees after a fixed positive non-diagonal mixing, without changing the canonical posterior; both have zero invalid quadrature mass. Reducing concentration from1000 to1 produces risk76.5804440698 and invalid mass0.78125. Diagonal transport leaves reproduction geometry unchanged in the same constructed test.

Maxdet selection is discontinuous: perturbing a duplicate patch by +/-1e-8 switches the lexicographic triple from[0,1,2] to[1,2,3] and changes canonical coordinates substantially while both frames remain valid. An exact duplicate uses the first exact tie. This is not a smooth frame or a new mathematical theorem. Floating precision, tie changes, ill conditioning, support changes, nonpositive predictions and fallback branches limit the equivariance claim. Positive well-conditioned mixing tests apply only to jointly valid cases. Token variance uses an FP64 second-moment computation and 1e-24 variance floor for a finite sqrt derivative; finite precision may affect nearly constant token standard deviations. No claim is made that real camera spectral responses follow a single GL(3) map.

## Independent numerical review fixes

The independent reviewer found two P2 helper defects beyond the initial16 tests: an absolute normalization epsilon/overflow made canonical GT depend on its arbitrary positive magnitude, and separately evaluating logC(k)+k dot lost the concentrated vMF peak by cancellation. These were interface correctness bugs; no real-data impact was measured. Two added regression tests failed against the reviewed code before the fixes.

`canonical_target` now removes positive common GT magnitude and common absolute frame magnitude before the FP64 solve, then removes the solved vector's absolute magnitude before taking its Euclidean norm. The camera Jacobian also removes common frame magnitude, which algebraically cancels, before computing transported length. Direction, canonical NLL and camera NLL are tested invariant across GT scales1e-15/1e-100/1e200 and opposing GT/frame scales1e-200/1e200 and1e200/1e-200. A numerically nonfinite solve now explicitly raises rather than producing a nonspherical target. These helpers still require nonsingular numerically supported frames.

The k>=1 complete vMF density now evaluates `log(k)-log(2*pi)-log(1-exp(-2*k))-(k/2)||mu-q||^2`. For unit directions this is algebraically the same exponent, while squared chord distance preserves tiny angular offsets that rounding can erase in `dot-1`. A bounded small-k branch retains the uniform-limit calculation. The new full-density test checks the float32 k=1e20 aligned NLL against **-44.213825**, and a1e-10 tangent offset adds **0.5** NLL with finite gradients. This fixes the cancellation that the isolated-normalizer test could not detect. The external posterior direction interface assumes unit vectors as specified; no claim extends to arbitrary nonunit directions or mathematically unrepresentable losses.
