## Provenance and formulation

The implementation is marked MODIFIED/ADAPTED and retains the Google2017 Apache-2.0 notice and original-file references. Formulas were read from the pinned unmodified `docs/research/cc_v3_sources/google_ffcc/` reference at commit`2fa9e1316954dbd3913630b7d597927941b4dd32`, alongside `docs/research/cc_v3_prior_art.md`. Pinned LICENSE remains in that reference. No license inference is made about datasets, weights, MATLAB or minFunc.

The source-grounded compact control uses two feature channels: masked linear RGB and exact eight-neighbor mean absolute difference weighted by center/neighbor mask products. Image and mask edges replicate. The double path's undefined deviation when no neighbors are valid becomes NaN and is excluded from histogram votes. Input histograms use nearest-bin MATLAB half-away-from-zero rounding, periodic wrapping, u rows/v columns, and unit counts; each channel normalizes independently and empty channels remain zero. Defaults:64 bins, spacing1/32, origin-0.4375, minimum feature channel intensity1/256. There is no intensity weighting or bilinear input splatting.

Two trainable real spatial filters plus a bias map produce exactly **12,288 parameters** at64 bins. Initialization is zero, matching the shallow source initialization. Forward computes `real(ifft2(sum(fft2(hist)*fft2(filter))))+bias`, with no conjugation, kernel centering, fftshift or gain map. Stable softmax produces a normalized PMF. The pinned shallow source has no paper-style gain map.

The circular moment decoder returns a zero-based mean. Covariance reproduces the source's **one-based rounded torus chart**, then adds eps_bins*I (default1) and converts to UV units with h². No forced isotropy, covariance clamp or additional numerical jitter is used. Gray-light decoding is default; optional Gray-World de-aliasing uses the normalized **all-spatial-pixel linear RGB mean**, preserving the source distinction from mean log chroma. Explicit mask values affect feature votes and local differences, but do not alter this original-image spatial average. Existing zero pixels participate. UV-to-RGB uses normalized `[exp(-u),1,exp(-v)]`, with common-log-scale subtraction for numerical stability.

Cross entropy supports explicit `kind='nearest'` (source SMOOTH_CROSS_ENTROPY=true) and `kind='bilinear'` (source false). The Gaussian UV likelihood uses the nonwrapped residual after decoder de-aliasing and subtracts `log(2*pi*eps_bins*h²)`, matching the source likelihood shift. It is not the exact BVM density. Cholesky solve replaces explicit inversion without adding jitter. Full-FFT quadratic regularization uses the source difference-kernel spectral weights, including the FFT/Parseval scaling, default filter lambda=n^-4, filter shift=2^-8, bias lambda1 and bias shift2^-8. `data_mass` explicitly scales the regularizer; averaged objectives use mass1 and summed objectives use total sample weight. It is not L1 TV or AdamW decay.

## Interfaces

- `FFCCInspiredNet(n=64,h=1/32,lo=-.4375,eps_bins=1,unwrap_mode='gray_light')`; alternative unwrap mode`gray_world`. `forward(rgb,mask=None)` accepts floating Nx3xHxW RGB in[0,1] and optional boolean NxHxW mask. Absent mask defaults to all channels>0, matching GehlerShi MASK_ZERO_PIXELS. Invalid shape, nonfinite or out-of-range inputs raise; no implicit image scaling/clipping.
- `featurize(...)` returns `hist` Nx2xnxn, normalized `average_rgb` Nx3, `average_valid`, and `feature_counts` Nx2. Histograms and local differences use FP64, resolving the source float-type ambiguity with an explicit full-scale1 policy. Integer/bitshift paths are not implemented.
- `forward_histograms(hist,average_rgb=None)` supports cached features. It casts histograms to parameter dtype for filtering; call`model.double()` for FP64 FFTs. Output additionally exposes `logits`, `pmf`, `mu_index`, `mu_uv`, `covariance_uv`, `pred`, `resultant`, `mean_valid`, `anchor_valid`, `confidence_raw`, `confidence`, `feature_valid`, and `valid`.
- Independent helpers: `round_matlab`, `periodic_histogram`, `masked_local_absolute_deviation`, `circular_score`, `decode`, `rgb_to_uv`, `uv_to_rgb`, `target_distribution`, `cross_entropy`, `gaussian_uv_nll`, `fft_regularizer`. Loss helpers support reductions`mean`,`sum`,`none`. Model`regularizer(data_mass=1,**kwargs)` delegates to the source FFT objective.

Circular means are declared undefined when either resultant is<=1e-10. Such axes use a finite zero-index diagnostic, `mean_valid=False`, and confidence0. `confidence_raw` retains the covariance-only source formula for inspection. This refusal is an explicit safety adaptation to mathematically undefined uniform/balanced posteriors, not a source confidence estimate. `valid` additionally requires some histogram feature mass and a positive RGB prediction. `gaussian_uv_nll` **raises if any row has an undefined mean**, avoiding silent zero objectives or implicit selective fitting. Use cross-entropy warmup and inspect resultants before invoking the NLL stage. Other row exclusions must be explicit in the caller. Confidence is concentration, not calibrated error or a selective guarantee.
