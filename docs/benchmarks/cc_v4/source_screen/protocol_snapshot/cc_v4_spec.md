# V4 correction-conditioned evidence routing: experimental specification

Decision frozen for the first implementation on 2026-09-10. Status: **UNVERIFIED HYPOTHESIS**, not a novelty or universal-accuracy claim. Source review: [visual training](cc_v4_visual_training_sources.md), [efficient training](cc_v4_efficient_training_sources.md), [photometry](cc_v4_photometric_sources.md), [independent critique](cc_v4_action_field_critique.md).

The selected mechanism evaluates corrections by transporting cached local color evidence and changing its relative contribution. A compact encoder runs once. It emits image context and local candidate illuminants. A small shared router sees local context and the color that a candidate correction would leave. The expected reproduction error of the local hypotheses gives a bounded decision field. Its weights depend on the proposed correction; consequently it is a decision field, **not one coherent illuminant posterior**. A matched router with action-independent weights is the decisive posterior control.

## Scope and equations

Single nonnegative linear camera-RGB image, no camera identity or EXIF. A is log(R/G),log(B/G) of an illuminant divisor, b the measured GT in the same chart. Corrected local log chroma is z_p-a. Camera is one condition axis alongside surface/color diversity, scene, illumination, exposure and processing. Only the declared linear/global model has exact supervision now. Unknown ISP/JPEG and spatially varying illumination are future measured domains, not silently covered.

For residual r=(exp(b_R-a_R),1,exp(b_B-a_B)), define c=1-(sum r)^2/(3 sum r^2) and alpha=angle(r,ones). Analytic target gradients are independently checked in cc_v4_geometry.py. Dense actions reuse the same two GT coordinates and do not add independent samples. Value/derivative supervision is known Sobolev training.

Let f_p be cached local features, z_p local mean log chroma, s_p local RMS log chroma, k global context, a0 the direct predictor, and b_p positive local hypotheses. Define T(z,a)=(3p_R-1,3p_B-1), p=softmax([z_R-a_R,0,z_B-a_B]): the nonlinear centered chromaticity after the candidate correction. Proposed weights are softmax_p router(f_p,k,T(z_p,a),T(s_p,a),a-a0). A generic action control uses T(z_p,a0),T(s_p,a0),a-a0; the posterior control uses the same with last input0, so weights are action-independent. All evaluate R_c(a)=sum_p w_p(a)c(b_p,a) and R_alpha(a)=sum_p w_p(a)alpha(b_p,a). Select using R_alpha, not arcsin(sqrt(mean c)), which is not mean angle. Local hypotheses are latent proposals, not local GT measurements. Action-dependent weights can exploit the search, so selected-action regret must be measured. Preflight review established that the original purely linear log-transport draft was absorbable into the first layer; this nonlinear amendment and additional null were made before any training, not selected by validation error.

First implementation uses a scratch MobileNetV3-large feature extractor (the established strong 3M control), plus independently implemented transport/router. This isolates a new inference mechanism without weakening image features merely to make every layer unusual. No external weights, semantic teacher or language model. New whole-network alternatives can follow evidence; the encoder name itself is not the contribution.

## Task 2: source-only training integration and screen (root)

Frozen source cache identities and1126 train/119 validation capture roles from V3; no new INTEL GT, no462 source test/risk259/cal268 decoding. Same128 input, scratch initialization, seed17, batch32, AdamW.001/weight_decay.0001, cosinefloor2e-5, clip5,120 epochs; horizontal flips and common exposure only in first architecture screen. No color invariance loss. Architecture comparison shares encoder, point, vote/router parameters and training objective. All modes receive point reproduction loss and action value loss; full derivative supervision is a separate ablation after a viable value-only field. Matching these budgets does not claim identical FLOPs.

Sample actions independent of GT given image: equal mixes of detached model point ±U[-.4,.4] and global U[-1.5,1.5]; include detached point. Never center the sampler on GT. Targets use actual real illuminant, no teacher pseudo-truth. Value losses squared sin2 error and squared angular/45 error; point objective actual reproduction degrees. Freeze exact loss weights in runner config before starting, with warmup schedule if needed; disclose. These train a primary decision estimator. **Reliability calibration is later fitted to held-out selected-action residuals**, not in-fold action losses.

One source-only pilot and a fixed120epoch three-way posterior/action/transport screen are development evidence, not an independent benchmark or a completed C+ selective comparison. Direct point is a readout/policy control within each trained model, with its own best checkpoint; no redundant identical direct training. Checkpoint choice minimum validation mean. Archive all histories/checkpoints metadata/source hashes and failures. Compare original point versus searched output, candidate-oracle versus selected error, risk coverage (raw/uncalibrated explicitly), tails, training allocator peak, parameters and actual latency in a separate fresh-process benchmark. If transport loses to posterior/action control, choose the simpler winner for further accuracy work and keep the negative.

## Novelty boundary

Borrowed: candidate correction evaluation (Multi-Hypothesis2020), image-conditioned feature modulation (SAFE2026), raw illumination intervention/ equivariance (CLCC2021 and later work), iterative residual judgment (VLM-CC2026), value/gradient training (Sobolev2017), teacher/student compression including TPAMI2025 color constancy. Investigated contribution: **cached local evidence transported under actions, action-dependent hypothesis support, and real reproduction-cost supervision, with measurable selection risk per unit compute**. No first/patentability claim; a broad posterior approximation can represent the same Bayes decision risk.
