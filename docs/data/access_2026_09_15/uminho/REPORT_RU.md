## Что действительно восстановлено

Проверены существующие кэши текущего workspace: исходных `.mat`, P1 palette/masks и старых P2 checkpoint нет. Старые строки отчётов о скачивании не считаются наличием данных сейчас.

В архивном `chromaseed_palette_pretrain_v1/source_lock.json` сохранены **все 19 исходных TRAIN-файлов, точные размеры и SHA256**. Проверен SHA256 самого source lock `db5e5c8d9eef8f7a066a0fac8296956507ceb59522b8ffb95b7f86ab8b5b2cf7`. Из него восстановлен отдельный локальный manifest с настоящими исходными именами; эти имена не добавлены в новые публичные материалы. Общий ожидаемый размер 19 кубов — **1 975 360 986 байт**. Это восстановление прежних данных и распределения, не новый split или новый эксперимент.

SHA256 локального `data/public/uminho_access/train_manifest.private.json`:
`f99a53a6c4c2b752dd417ed8ce19c1c0becd415e46cb7e2fe681bbe05144daf9`.

Исходные байты полного manifest 29 лиц с SHA256 `3d3b7dc7256eb04250dee2f5ef76880f4101d019313d97ba051480f8d320b5c7` отсутствуют. Для TRAIN это не блокер: точный состав 19 лиц прямо сохранён в source lock. Полное разделение пяти validation и пяти test внутри остальных десяти здесь заново не объявляется восстановленным. Ни один из десяти held-out кубов не получен и не открыт.

Новый [загрузчик](../../../../scripts/data_access/uminho_restore.py) переносим: получает только 19 зафиксированных исходных имён из официального API, проверяет прежний CC BY 4.0, размер, авторский MD5 и исторический SHA256. Уже существующие файлы сначала проверяет; несовпадения и незавершённые загрузки не перезаписывает. Реальная декодировка недоступна до получения хотя бы одного оригинала: [audit.json](audit.json) честно содержит `NO_SOURCE_CUBES`, 0 кубов и 0 спектров.

## Проверенный контракт подготовки

Из прежнего кода и проверенных оригинальных таблиц CIE восстановлен независимый от P2 тракт интегрирования. [contract.json](contract.json) и [canonical_integration_matrices.npz](canonical_integration_matrices.npz) содержат реально пересчитанные матрицы и контрольные суммы; это математический компонент, не новые приборные labels для фотографии.

| Поле | Контракт |
|---|---|
| Исходный массив | MATLAB `datao`, float64, H×W×33 |
| Спектральные узлы | 400…720 нм, шаг 10 нм |
| Физическая величина | Безразмерное направленное спектральное отражение; значения выше 1 сохраняются |
| Background | Полностью нулевые спектры — искусственный фон; nonzero foreground не равен проверенной skin-only маске |
| Расчётный XYZ | Нормирован к Y=1 идеального отражателя; для шкалы Y=100 умножаются все XYZ на 100 |
| Наши отдельные конвенции | D65/CIE1931 2° и D65/CIE1964 10°; массивы не объединяются |
| Интегрирование | Сетка 360…830 нм, 1 нм; линейная интерполяция и постоянные крайние значения вне 400…720 нм |
| Авторские JPEG | Производный D65/CIE2006 10° render, не независимая фотография камеры и не та же конвенция, что CIE1964 10° |
| Camera/illumination augmentation | Не выполнялись; нет псевдо-Lab, новых камер или новых физических измерений |

Белый XYZ при Y=1: 2° — `[0.9504705586542832, 1.0000000000000002, 1.0888287363958846]`; 10° — `[0.9481106006237401, 1.0000000000000002, 1.073046695432118]`. Идеальный отражатель даёт Lab `[100,0,0]` с абсолютным численным отклонением ниже 1e-10. Это проверка вычислений. Постоянная экстраполяция вне измеренного спектра, конечная ширина фильтров и направленность отражения остаются физическими ограничениями; численное совпадение не устраняет их.

## Сопоставление с P1/P2

Исторический P1: 19 456 спектров / 19 TRAIN-лиц, Seg1 skin mask и 1024 выбранных участка на лицо. Исторический P2: 2432 пространственных участка × 8 расчётных видов = 19 456 примеров; вход 18 статистик, цели 33 спектральные координаты плюс расчётный Lab D65/10°. Эти прежние результаты не повторялись и не объявляются полученными сейчас.

**Старые P2 веса не нужны для новой подготовки из кубов.** Данные отражения и интегрирование восстанавливаются независимо. Однако точная побитовая реконструкция старого P1/P2 требует прежних Seg1 weights (`1203cbc5ed2ee17cb2a408c47a23b3a28468f169d48b4d3cee8bd3059e7fbed3`), масок/выборки и положительных ROI-аннотаций; их нет. Замена Seg1 новым parser или выбор всех foreground пикселей изменит протокол и не должна называться точным восстановлением P1.

После получения исходных кубов допустима новая отдельно зафиксированная подготовка спектрального supervision на тех же 19 TRAIN-источниках с заново проверенными масками. В этом запуске никаких новых архитектур, spectral pretraining, BioSkin или MSKCC search не выполнялось. C_REBASE_V1 не изменён.

## Выполненные команды и точка продолжения

```bash
python scripts/data_access/uminho_restore.py inventory
python scripts/data_access/uminho_restore.py contract
python scripts/data_access/uminho_restore.py audit
```

Все три команды выполнены. Первая проверила архивный lock и восстановила точный TRAIN-list, вторая проверила CIE tables и вычисления, третья установила отсутствие исходных кубов. Проверка HTTP выполнена `urllib.request.urlopen` по API_URL; состояние отдельно сохранено в access receipt. Полная загрузка кубов и их real-data decode не выполнены.

Когда официальный API станет доступен из разрешённой среды:

```bash
python scripts/data_access/uminho_restore.py download --receipt data/public/uminho_access/download_restored.json
python scripts/data_access/uminho_restore.py audit --receipt data/public/uminho_access/audit_restored.json
```

Для снятия текущего блокера достаточно доступности официального API/download либо прикреплённых владельцем оригинальных TRAIN `.mat`, совпадающих с сохранёнными SHA256. Новые платные ресурсы и потерянный P2 checkpoint не требуются. UMINHO не блокирует ENCoDE, STW или реальные repeated-capture данные.
