# Experiment plan v0.1 — [PROPOSAL]

## Проверяемая гипотеза
Совместное обучение надежности ROI, ограниченной фотометрической коррекции и оценки ошибки по расхождению допустимых фотометрических объяснений улучшает ошибку канонического цвета при фиксированном coverage по сравнению с сильной комбинацией известных методов.
Одно лишь сочетание сегментации, коррекции света, fine-tuning и reject-head не считать новым методом.

## Baselines
A0: текущий YuNet + cheeks + robust RGB/Lab, без изменений.
A1: те же ROI + Gray World / Shades of Gray; применять и вариант без принудительной WB.
A2: глобальная и региональная CCM; отдельно явно обозначить режим известной калиброванной камеры.
B: готовое подходящее решение constancy; C5 проверять в его RAW/transductive режиме, не подменять обычным JPEG. Research-only код только после проверки допустимости именно этого использования.
C: MobileNetV4-Conv-Small + обычная Lab-регрессия, тот же dataset и бюджет.
C+: learned ROI + известная коррекция + обычный fine-tuning + post-hoc error calibration.
P: предлагаемый ROI/photometric ambiguity/risk метод. P должен выигрывать у C+, а не только у A0.

## Primary endpoint
Средняя ΔE00 на принятых кадрах при фиксированном 80% coverage на заранее выделенных camera/light holdouts; сравнить с лучшим допустимым baseline. Также полный risk–coverage, p95 ошибки и P(ΔE00>tau).
Coverage считать по всему входящему потоку и отдельно по кадрам, технически пригодным к оценке. Порог отбирать на calibration, не на test. Ретейк и недоступность сервиса — разные исходы.
Пример исследовательской цели: относительное снижение ошибки на 15–20%, доверительный интервал парного различия исключает ноль. Это ориентир продолжения, НЕ достигнутая метрика. tau определить по пилоту и косметическим требованиям; 4 ΔE00 — лишь проверяемый стартовый вариант.

## Secondary endpoints
MAE/RMSE каналов Lab; внутриличностная camera/light стабильность вместе с абсолютной ошибкой; сохранение межличностного диапазона цвета; IoU/Dice масок пригодной кожи; calibration для события ΔE00<=tau (ECE/Brier); false accept непригодных кадров; false reject пригодных; результаты по camera и диапазонам измеренного цвета.
Для uncertainty обычный detector score или softmax не использовать как доказательство.

## Ablations
Убрать по одному: learned ROI; ограниченную коррекцию; отдельную цветовую ветвь; парную согласованность; устройство/метаданные; фотометрическое расхождение; калибровку error head; teacher; synthetic augmentation. Сравнить FP32/FP16/INT8 после повторной калибровки.
Обучать error head на out-of-fold ошибках, не на оптимистичных in-sample residuals.

## Статистика
Единица независимости — человек/блок, а не кадр. Bootstrap по людям. Зафиксировать seeds, primary metric, subgroup cuts и selection rules до теста. Повторные эксперименты на одном test превращают его в validation; нужен новый lockbox.
Conformal/CRC не дают безусловную гарантию для произвольной новой камеры. Для множества reject-порогов нужен корректный risk-controlling selection, например Learn-then-Test, с проверкой предпосылок и зависимостей внутри людей.

## Compute benchmark
Измерить batch=1 model-only и end-to-end p50/p95: decode, ICC, YuNet, ROI, transfer, model, Lab/calibration. Отдельно concurrency=2, VRAM peak, reserved/allocated, serialized model/ONNX/engine size, параметры, энергия на кадр. Фиксировать GPU driver, CUDA, runtime, resolution и warmup. Не переносить опубликованные Pixel/iPhone результаты на RTX 4060.

## Stop / pivot
Нет надежного GT -> не заявлять абсолютную цветометрию.
P не выигрывает у C+ -> оставить более простую систему, пересмотреть научную новизну.
Большая ошибка при приемлемом coverage -> guided recapture или режим с картой/калибровкой; не скрывать переход от одного фото к нескольким.
