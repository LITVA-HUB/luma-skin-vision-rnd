# Luma — стартовый пакет R&D
Дата аудита: 10 сентября 2026 года.

Это дополнение к аналитическому заключению в ответе, а не готовый vision engine и не доказательство его качества.
Новая модель не обучена. Все целевые характеристики являются предложениями. Результаты ΔE00, risk–coverage, RTX 4060 latency/VRAM: НЕ ИЗМЕРЕНО.

## Состав
- audit_evidence.md: проверяемые места в предоставленном репозитории и границы проверки.
- archive_manifest.txt: фактический состав исходного ZIP.
- vision_smoke_check.json: единственный выполненный smoke-check на встроенном фото; CPU, не RTX 4060; не accuracy benchmark.
- dataset_protocol.md: предлагаемый минимальный протокол данных и измерительного эталона.
- experiment_plan.md: сравнения, метрики, защита от утечек и условия продолжения.
- experiment_registry.json: незаполненный реестр экспериментов; значения метрик null.
- proposed_rejection_contract.json: пример нового контракта отказа; НЕ текущий API Luma.
- source_index.md: основные внешние источники и границы проверки.

[PROJECT FACT] подтверждено файлами переданного архива либо явно обозначенным локальным запуском.
[EXTERNAL FACT] подтверждено указанным внешним источником.
[INFERENCE] инженерный вывод, не измерение.
[PROPOSAL] предлагаемая разработка, не существующая функция.
